EasyTapTabs — スペースキーで作るタブ譜

メトロノームに合わせてキーボードの Space キーを叩いて「リズム（タイミングと音の長さ）」だけを先に記録し、あとから弦とフレット番号を埋めていく方式のギター・ベース用TAB譜作成ツールです。

ブラウザ上でそのまま動きます（インストール・会員登録不要） PCのキーボード操作に最適化しています。作成した譜面はJSON保存やPDF印刷に対応。

なぜ「リズムが先、フレットが後」なのか

一般的なTAB譜作成ソフトや楽譜エディタは高機能ですが、耳コピしながら譜面を書くときに「ここは16分音符だから音価を切り替えて、休符を入れて、付点をつけて、タイで繋いで……」と計算しながら入力するのがとにかく面倒でした。

フレーズが頭の中で鳴っているときは、音符の種類を計算するよりも、メトロノームに合わせて机やスペースキーを「タッカ・タッカ・ターン」と叩く方が圧倒的に速く正確です。

そこで本ツールでは、「最初は音程（何弦の何フレットか）を一切気にせず、リズムと音の長さだけをリアルタイムで打ち込む」という割り切った2段階の入力方式を採っています。リズムの枠さえできてしまえば、あとは矢印キーと数字キーでパズルを埋めるようにフレット番号を入れていくだけでTAB譜が完成します。

基本的な使い方（3ステップ）

STEP 1メトロノームに合わせてリズムを刻む

上部の操作盤で楽器（ギター6弦 / ベース4弦）とBPM、クオンタイズ（16分音符または8分音符・32分音符）を選び、「リズム採譜開始」を押します。4拍（または8拍）のカウントインが鳴ったあと、クリック音に合わせて Space キーを叩きます。キーを長押しした分だけ伸びる音符として記録され、譜面上に未確定の音符が並びます。

ギターのコードストロークなどを入力したい場合は、収録モードを「和音モード」に切り替えておくと、打鍵したタイミングのすべての弦に一括で音符が配置され、コード演奏をそのまま採譜できます。

STEP 2弦とフレット番号を割り当てる

記録された「?」をクリックして選択し、キーボードの数字キー（0〜24）でフレット番号を入力します。2桁のフレット（10〜24）もそのまま連続入力できます。↑ ↓ キーで弦を上下に移動でき、← → キーで前後の音符へ順番に移動しながら連続してフレットを埋めていけます。

STEP 3再生確認・五線譜切替・印刷（PDF保存）

「再生確認」ボタンを押すと、入力したTAB譜が内蔵シンセ音源で再生されます。タイ・スラーやチョーキング（半音・全音ベンド）のニュアンスもそのまま音に反映されます。完成した譜面は「保存」でJSONファイルとして手元に控えたり、「印刷 / PDF」からA4サイズに綺麗に収まる形で出力できます。また「楽譜表示」ボタンを押すと、タブ譜から自動変換された五線譜（ギターは8vbト音記号、ベースはヘ音記号）でも確認・印刷が可能です。

綺麗に採譜するための実用ティップス

1. 速いフレーズはBPMを落として収録する

BPM 160以上の速い16分フレーズなどを原曲テンポのままスペースキーで正確に叩くのは至難の業です。収録時はいったんBPMを 80〜100 程度まで落としてゆっくり確実にリズムを刻み、収録が終わったあとでBPMを本来の数値に戻してください。内部的には小節内のステップ位置で管理されているため、あとからBPMを変えてもリズムは一切崩れません。

2. 音声入力（マイク／オーディオIF）を使う場合は「ブラッシング」で刻む

スペースキーの代わりに、実際のギターやベースをオーディオインターフェースやマイクに繋いでリズムを入力する「音声入力（ストローク時のみ推奨）」機能も搭載しています。

実音ではなく「ブラッシング（ミュート音）」で刻む理由
実音をそのままジャラーンと鳴らすと、弦の残響音や倍音のうねりで音量しきい値を何度も跨いでしまい、意図しない細かい音符が連続で刻まれやすくなります。音声入力でリズムを録るときは、左手で全弦に軽く触れてミュートし、「チャッ、チャッ」というブラッシング（パーカッシブなアタック音）の形でストロークやピッキングを行ってください。アタックの立ち上がりだけが綺麗に検出され、狙い通りのリズムが刻めます。

3. 1小節だけ録り直したいときは小節左上の「●録音」を使う

「3小節目だけリズムをミスした」という場合、全体を通しで録り直す必要はありません。各小節の左上にある「●録音」ボタンを押すと、カウントインのあとにその1小節だけをピンポイントで上書き収録し、小節の終わりに自動で停止します。また、同じリフが続く場合は小節の「コピー」「貼付」ボタンでそのまま複製できます。

キーボード操作・ショートカット一覧

マウスとキーボードを行き来する手間を減らすため、ほぼすべての編集作業がキーボード単体で完結するように設計しています。

Space 採譜中：リズム打鍵（長押しで延音）／ 再生中：再生の即時停止
← / → 前後の音符へ選択フォーカスを移動（小節をまたいで移動可能）
↑ / ↓ 単音時：選択中の音符の弦を上下に移動
和音時：同じタイミングの上下の弦にある音符へフォーカス移動（Shift + ↑/↓ で弦自体を移動）
0 〜 9 フレット番号の入力（1 → 2 と素早く押すと12フレットとして認識）
C 収録モードの切替（単音モード ↔ 和音・全弦モード）
A または Alt+↑/↓ 選択中の音符と同じタイミングの別弦に音符（?）を追加して和音化
Shift + C 選択中のイベントの空いているすべての弦に未確定音符（?）を一括展開
T （または S） タイ／スラーのON/OFF切替（次の音符と同じフレットならタイ、別フレットならスラーとして再生・描画。複数選択での一括適用にも対応）
B チョーキング（ベンド）の切替。押すたびに「なし → 半音(1/2) → 全音(Full) → なし」と切り替わります
X ゴーストノート（X / ミュート音）のON/OFF切替
[ / ] （または - / +） 選択中の音符の長さ（音価）を1ステップ単位で伸縮
Shift + ← / → 選択中の音符の発音タイミング自体を前後に1ステップずらす
Delete / Backspace 選択中の音符を削除（削除した部分は自動的に適切な休符に変換されます）
Ctrl+Z / Ctrl+Y 元に戻す（Undo） ／ やり直す（Redo）

対応している記譜・機能仕様

対応楽器・チューニング ギター（6弦）およびベース（4弦）に対応。チューニングはレギュラー（Standard）、半音下げ（Half Step Down）、全音下げ（Whole Step Down）、ドロップD（Drop D）から選択でき、再生音と五線譜の変換に即座に反映されます。
分解能・クオンタイズ 1小節あたり最大32ステップ（32分音符単位）。収録時の自動クオンタイズは「8分音符」「16分音符」「32分音符」から選択可能で、音符の隙間は全休符〜32分休符まで音楽理論に沿って自動分割・描画されます。
奏法・ニュアンス記譜 タイ・スラー（曲線描画およびレガート再生）、ゴーストノート（X表記およびパーカッシブなミュート音再生）、チョーキング（半音 1/2・全音 Full のベンド矢印描画およびWeb Audio APIによる滑らかなピッチベンド再生）に対応。
レイアウト・出力 1段あたりの横小節数を 1〜8小節（標準4小節）から自由に切り替え可能。画面ズーム（50%〜150%）、JSON形式でのプロジェクト保存・読込、ブラウザ印刷機能を使ったA4・PDF出力に対応しています。

よくある質問（FAQ）

Q. 作成した譜面データはサーバーに送信されますか？
いいえ。作成中の譜面データはすべてお使いのブラウザ内（LocalStorage）にのみ自動保存されます。外部のサーバーへ譜面データが送信・保存されることはありません。別PCへデータを移したい場合やバックアップを取りたい場合は、画面上部の「保存」ボタンからJSONファイルとしてダウンロードしてください。
Q. 和音の構成音の一部だけにタイやスラーをかけることはできますか？
可能です。和音の中の特定の音符だけをクリック（または Shift / Ctrl を押しながら複数クリック）して選択し、T キーを押すか画面下部インスペクターの「タイ/スラー」ボタンを押すことで、選択した弦の音符だけに弧線を引くことができます。
Q. スマートフォンやタブレットでも使えますか？
画面上の「打鍵」ボタンのタップ操作やインスペクターのボタン操作に対応しているため閲覧・簡易編集は可能ですが、数字キーでの素早いフレット入力や矢印キーでの移動を前提に作っているため、PC（Chrome / Edge / Firefox / Safari）での利用を強く推奨します。
Q. 商用利用や動画・ブログへの譜面掲載は自由ですか？
本ツールで作成・出力したTAB譜や五線譜の画像・PDFを、ご自身のYouTube動画、教則ブログ、バンド内の共有資料などに掲載・利用していただくことは完全に自由です（クレジット表記等も不要です）。ただし、著作権のある楽曲の譜面を公開する場合は、各楽曲の権利規定に従ってください。
