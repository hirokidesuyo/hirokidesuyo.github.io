はじめての使い方

EasyTapTabs は、メトロノームに合わせてスペースキーを叩いてリズムを先に記録し、あとから弦とフレットを埋めていくTAB譜作成ツールです。音価を計算しながら入力する従来の楽譜エディタとは逆の発想で、「リズムが先、フレットは後」が基本の流れになります。このページでは、起動から譜面の完成までの3ステップを順に解説します。

STEP 1 メトロノームに合わせてリズムを刻む

まず上部の操作盤で楽器（ギター6弦 / ベース4弦）とBPM、クオンタイズ（8分音符・16分音符・32分音符）を選び、「リズム採譜開始」を押します。4拍（または8拍）のカウントインが鳴ったあと、クリック音に合わせて Space キーを叩いてください。キーを押している間だけ音が伸びる扱いになり、長押しした分だけ長い音符として記録されます。

ギターのコードストロークのように複数弦を同時に鳴らすフレーズは、収録モードを「和音モード」に切り替えてから叩くと、打鍵したタイミングのすべての弦に一括で音符が配置され、そのままの形で採譜できます。

STEP 2 弦とフレット番号を割り当てる

収録が終わると、譜面上に「?」の音符が並びます。「?」をクリックして選択し、キーボードの数字キー（0〜24）でフレット番号を入力してください。10〜24のような2桁のフレットも、数字を続けて押すだけでそのまま入力できます。

↑↓キーで弦を上下に移動でき、←→キーで前後の音符へ順番に移動できます。マウスに戻らず、矢印キーと数字キーだけでパズルを埋めるようにフレットを入れていくのが基本操作です。

STEP 3 再生して確認する

フレットを埋め終わったら「再生確認」ボタンで、入力したTAB譜を内蔵シンセ音源で再生できます。タイやチョーキングのニュアンスも音に反映されるので、耳で聴いてフレーズが合っているか確かめてください。完成した譜面の保存と出力については「保存と出力のしかた」のページで解説しています。

つまずきやすいポイントと対処

リズムがズレるときは BPM を落として録り直す

速いフレーズを原曲のテンポのままスペースキーで正確に叩くのは、なかなか難しいものです。収録時はいったん BPM を 80〜100 程度まで落としてゆっくり確実にリズムを刻み、収録が終わったあとで BPM を本来の数値に戻してください。内部的には小節内のステップ位置で管理されているため、あとから BPM を変えてもリズムは崩れないようにしています。

音の長さやタイミングが思った通りにならないとき

スペースキーを押している間だけ音が伸びる扱いになります。録ったあとの微調整はキーボードでできます。音符を選んで [ / ] を押すと音の長さ（音価）が1ステップ単位で伸縮し、Shift + ← / → で発音タイミング自体を前後に1ステップずらせます。

1小節だけミスしたら、その小節だけ録り直せる

全体を通しで録り直す必要はありません。各小節の左上にある「●録音」ボタンを押すと、カウントインのあとにその1小節だけをピンポイントで上書き収録し、小節の終わりに自動で停止します。同じリフが続く場合は小節の「コピー」「貼付」ボタンでそのまま複製できます。

間違えたらすぐ戻せる

Delete / Backspace で選択中の音符を削除できます（削除した部分は自動的に適切な休符に変換されます）。Ctrl+Z で元に戻す、Ctrl+Y でやり直すこともできます。

単音と和音の切り替えは C キーでもできる

収録モードの切替（単音モード ↔ 和音・全弦モード）は、画面のボタンだけでなく C キーでも切り替えられます。

完成したら保存しておく

作成中の譜面データはブラウザ内（LocalStorage）に自動保存されますが、別PCへデータを移したい場合やバックアップを取りたい場合は、画面上部の「保存」ボタンから JSON ファイルとしてダウンロードしておいてください。保存と出力の詳しい手順は「保存と出力のしかた」のページで解説しています。

よくある質問（はじめての人向け）

Q. スマートフォンやタブレットでも使えますか？

はい。スマートフォン向けのページ（モバイル版）を用意しているため、スマホでも編集できます。細かい操作は PC のほうがしやすい場面もありますが、外出先でスマホから譜面を直すといった使い方もできます。

Q. 作った譜面はサーバーに送られますか？

いいえ。作成中の譜面データはすべてお使いのブラウザ内にのみ自動保存されます。外部のサーバーへ譜面データが送信・保存されることはありません。

ブラウザ上でそのまま動き、インストールも会員登録も不要です。まずは短いリフを1小節だけ録ってみるところから始めてみてください。
