奏法記号の入力

フレーズのニュアンスを譜面に残すための、タイ/スラー、チョーキング、ゴーストノートの付け方を解説します。いずれもキーボードのキー1つで切り替えでき、再生音にも反映されます。

タイとスラー（Tキー）

音符を選択して T キー（または S キー）を押すと、次の音符との間に弧線が引かれます。次の音符と同じフレットの場合はタイ（音をつなげる）、別フレットの場合はスラー（レガート）として描画・再生されます。

和音の構成音の一部だけにかけたい場合は、対象の音符だけをクリック（または Shift / Ctrl を押しながら複数クリック）して選択してから T キーを押してください。選択した弦の音符だけに弧線を引くことができます。複数選択での一括適用にも対応しています。

チョーキング（Bキー）

B キーを押すたびに「なし → 半音（1/2）→ 全音（Full）→ なし」と切り替わります。譜面にはベンドの矢印と 1/2 / Full の表記が描画され、再生時には Web Audio API による滑らかなピッチベンドで再現されます。

ゴーストノート（Xキー）

X キーを押すとゴーストノートのON/OFFが切り替わります。譜面では X 表記になり、再生時にはパーカッシブなミュート音として鳴ります。リズムの刻みやファンキーなカッティングの表現に使えます。
