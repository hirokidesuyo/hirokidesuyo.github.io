キーボード操作とショートカット活用術

EasyTapTabs は、マウスとキーボードを行き来する手間を減らすため、ほぼすべての編集作業がキーボード単体で完結するように設計されています。このページでは、覚えておくと採譜が速くなる主要なショートカットを用途別に紹介します。

移動と入力の基本

キー 動作
Space 採譜中はリズム打鍵（長押しで延音）/ 再生中は再生の即時停止
← / → 前後の音符へ選択フォーカスを移動（小節をまたいで移動可能）
↑ / ↓ 選択中の音符の弦を上下に移動（和音時は同じタイミングの音符へフォーカス移動）
0〜9 フレット番号の入力（1→2と素早く押すと12フレットとして認識）
Delete / Backspace 選択中の音符を削除（削除した部分は自動的に適切な休符に変換されます）
Ctrl+Z / Ctrl+Y 元に戻す / やり直す

特に ←→ キーでの移動と数字キーの組み合わせは、STEP 2 のフレット埋めを高速化する要です。マウスで1つずつクリックするより、矢印キーで次々と送りながら数字を打ち込む流れに慣れると、採譜の速度が大きく変わります。

音符を編集するキー

キー 動作
[ / ]（または - / +） 選択中の音符の長さ（音価）を1ステップ単位で伸縮
Shift + ← / → 選択中の音符の発音タイミング自体を前後に1ステップずらす
T（または S） タイ/スラーのON/OFF切替
B チョーキング（ベンド）の切替（なし → 半音 → 全音 → なし）
X ゴーストノート（X / ミュート音）のON/OFF切替

複数選択して一括で適用することもできるので、フレーズ全体に同じニュアンスを付けたいときにも使えます。
